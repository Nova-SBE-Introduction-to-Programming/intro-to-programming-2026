# Introduction to Programming

From idea to app — building software with AI.

This course is not "learn Python". It is about turning an idea into working software, with AI doing most of the typing, and knowing enough to tell when it is wrong. The classic programming concepts are still here — but as the reading literacy you need to steer and verify an AI, not as things you are tested on by hand.

The semester runs like a developer onboarding: read a codebase first, build alone second, build together third, present last.

## The semester at a glance

| Block | Weeks | What happens |
|---|---|---|
| **1 · Join the company** | 1–4 | You get hired into a small company with an existing codebase (SplitIt or Tiny CRM). You read it, find the planted bugs, ship features from PM specs, and deploy. |
| **2 · Solo project** | 5–7 | You pick one of three cases and build it alone on the same skeleton. Never submitted — examined. |
| **3 · Team project** | 8–10 | Open scope. Groups pick the strongest solo project among their members and extend it together. |
| **Presentations** | 11–12 | Live demo at a deployed URL + code walkthrough. Half the groups each week. |

## Before you start

- [Setup](setup.html) — install Python, VS Code and Copilot, sign in to GitHub, run your first app. Do this before Class 1.
- [Evaluation](evaluation.html) — how the grade is built: one team presentation (40%) and one exam (60%).

Nothing is submitted on Moodle. Your work lives on GitHub; Moodle only carries links and announcements.
